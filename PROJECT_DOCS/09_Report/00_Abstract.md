# Abstract

Distributed Denial-of-Service (DDoS) attacks remain a critical threat to network availability. Software Defined Networking (SDN) centralises control and enables programmable traffic management, yet many SDN security prototypes rely on static thresholds, single-method detection, or stop at alert generation without automated mitigation. This project presents **IntelliShield SDN**, a self-evolving hybrid framework that integrates OpenFlow telemetry, multi-dimensional Shannon entropy analysis, hybrid machine learning, concept-drift detection, reinforcement-learning-based threshold adaptation, and surgical OpenFlow mitigation within a single controller application.

The system is implemented in Python on an Ubuntu 22.04 virtual machine using OsKen (OpenFlow 1.3), Mininet, and Open vSwitch. A central controller (`flow_monitor.py`) polls flow statistics every five seconds and orchestrates eight integrated phases: flow monitoring, entropy detection, traffic simulation, ML classification (Isolation Forest + Decision Tree ensemble on a 15-dimensional feature vector), automated mitigation with FLOW_PAIR surgical blocking, ADWIN drift detection, HDBSCAN traffic profiling, and PPO-based online threshold tuning. A FastAPI dashboard provides live monitoring and a Master Control panel for reproducible experiment execution.

Evaluation uses five predefined Mininet scenarios (normal baseline, SYN flood, UDP flood, burst, and mixed attacks) with ground-truth logging. Validation on the laboratory testbed demonstrates: normal traffic classified as NORMAL with zero false-positive blocks (Scenario 1); entropy collapse and ML ATTACK classification with SYN_FLOOD hints during SYN flood (Scenario 2); automated OpenFlow DROP rules with auto-expiring hard timeouts; and automated detection/mitigation latency reporting via `compute_metrics.py`. Typical detection latency ranges from five to twenty seconds in steady state, bounded by the monitoring interval and confirmation gates.

The contribution is an integrated, explainable, closed-loop SDN security architecture — not an isolated algorithm — combining fast heuristic signals, hybrid AI, adaptive control, and operator visibility. Release 1.0 extends that loop with cross-layer correlation, reliability-aware fusion, multi-stage verification, RCA/XAI, and policy alerting on shared contracts, plus a read-only snapshot twin for observational replay.
